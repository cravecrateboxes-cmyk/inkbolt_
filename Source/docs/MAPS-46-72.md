# New maps 46–72 (owner-approved list)

This is the plan for the next 27 campaign maps. Build them in a separate session, 3–4 maps per batch.

Every map needs a theme (`src/data/themes/<id>.js`), a kit (`blender/fam_kit_<id>.py`), a look entry (`src/data/looks.js`) and an e2e walk test.

The tactical look (light volume, shadows, decals, clutter) applies automatically.

Asset quality must meet the bar set by the asset upgrade pass. See [docs/tactical-look/UPGRADE-BRIEF.md](tactical-look/UPGRADE-BRIEF.md): no primitive-looking props.

## Decide before building

- **Progression past level 45:** player level cap (50 today), enemy scaling, XP, weapon unlocks.
- **Download size:** the game is about 43 MB today. Consider loading kits only when their map is played.
